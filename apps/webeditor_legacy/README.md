# EchoForge WebEditor Legacy UI

This is the old React/Vite video-editor UI revived for EF_CLEAN.

Run from EF_CLEAN root:

```bat
python scripts\open_webeditor_legacy.py
```

Or run:

```bat
apps\webeditor_legacy\run.bat
```

Backend: http://127.0.0.1:8765
Frontend: http://localhost:5173

This version stores the editor file at `projects/<project>/editor/editor_project.json`.
